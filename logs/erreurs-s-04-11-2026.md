Attente initiale K3s : kubectl wait a répondu no matching resources found avant l’enregistrement du nœud. Correction : attente de l’apparition du nœud avant le contrôle Ready.

Charge Podinfo : ApacheBench sans -l a compté 1020291 variations de longueur comme Failed requests, avec Connect 0 et Receive 0. Correction : ab -l, puis vérification complémentaire de 30 secondes, 371762 requêtes et zéro erreur. Les deux logs sont conservés.

Connexion Docker Hub par code : deux tentatives ont échoué avec Global rate limit exceeded. L’utilisateur a terminé docker login --username etest15 dans sa fenêtre interactive. La publication et le téléchargement anonyme ont ensuite réussi.

Accès navigateur : le premier Checkout utilisait un nom .test non déclaré dans hosts. Le paiement a réussi mais le retour a échoué en résolution DNS. Windows a refusé la modification de hosts. Correction : adresses sslip.io puis contrôle de la page de succès de la même session avec la nouvelle adresse.

Validation publique Docker Hub depuis le Python Windows : échec TLS certificate verify failed: certificate has expired. La même vérification a été exécutée depuis Ubuntu avec validation TLS active et a réussi. Aucun contrôle de certificat n’a été désactivé.
